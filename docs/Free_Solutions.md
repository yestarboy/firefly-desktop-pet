# Live2D 桌宠 - 完全免费方案

## 方案 1：继续使用我们的 Python 版本（推荐）✅

**优点**：
- 完全免费
- 已经实现基本功能
- 可以自定义

**缺点**：
- 需要一些调试
- 性能不如专业软件

**使用**：
```bash
cd D:\AI
python live2d_desktop_pet.py
```

---

## 方案 2：使用 Vtube Studio（免费）

**下载**：https://denchisoft.com/

**特点**：
- 完全免费
- 主要用于虚拟主播，但也可以当桌宠
- 完美支持 Live2D Cubism 4.0
- 支持面部追踪（如果有摄像头）

**使用步骤**：
1. 下载安装 Vtube Studio
2. 导入 Firefly.model3.json
3. 设置为窗口模式
4. 调整大小和位置

---

## 方案 3：直接用浏览器（最简单）

我们之前创建的网页版本可以直接用！

**使用步骤**：
```bash
cd D:\AI
python -m http.server 8000
```

然后在浏览器打开：
http://localhost:8000/live2d-viewer/index.html

**优点**：
- 完全免费
- 模型显示完美
- 可以全屏或调整窗口大小

**缺点**：
- 需要浏览器窗口
- 不是真正的桌宠

---

## 方案 4：使用 OBS Studio + Browser Source（免费）

**下载 OBS**：https://obsproject.com/

**步骤**：
1. 安装 OBS Studio（免费）
2. 添加 Browser Source
3. URL 设置为我们的网页版
4. 设置为投影仪模式
5. 调整为无边框窗口
