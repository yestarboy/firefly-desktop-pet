# motions

放 MMD 动作文件（`.vmd`）。**不入库**（体积 + 授权问题）。

## 怎么用

把下载到的 `.vmd` 放进来，命名随意，例如：

```
assets/models3d/motions/idle.vmd
assets/models3d/motions/talk.vmd
```

然后告诉我，我会：

1. 用 `VmdLoader` 加载
2. 用 `MmdRuntime` 循环播放
3. 截图确认动作和骨架对得上（不会手臂乱扭）

## 格式要求

- `.vmd`（MMD 动作），160 字节文件头 + 骨骼关键帧
- **必须和模型的骨架匹配**：VMD 里记的是骨骼名（センター / 上半身 / 左腕…），
  不同作者的模型骨骼名不一致就会错位或完全不动
- 建议先用"待機モーション"这类全身循环动作测试是否匹配
